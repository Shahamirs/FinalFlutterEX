# Flutter Quiz - Antigravity

Экзаменационное задание: "Разработка тестирующего приложения на Flutter (MVVM)".

## Описание
Приложение «Flutter Quiz» предназначено для прохождения теста по Dart/Flutter.
Включает 10 вопросов, покрывающих основы Dart, работу с виджетами, структуру проекта и архитектуру.

Приложение реализовано с соблюдением эстетичного современного дизайна (поддержка Dark Mode по умолчанию, современные шрифты Google Fonts — Outfit / Inter).

## Архитектура
Использован паттерн **MVVM** (Model-View-ViewModel):
- **Models**: `question.dart`, `quiz_result.dart` (состояние и данные теста)
- **Services (Data)**: `quiz_service.dart` (загрузка вопросов из локального JSON)
- **ViewModels**: `quiz_view_model.dart` (бизнес-логика ведения теста, подсчет очков, управление состоянием через `ChangeNotifier`)
- **Views (UI)**: `home_view.dart`, `quiz_view.dart`, `result_view.dart` (отделены от логики, подписаны на изменения через `Provider`).

## Требования
- Минимальная версия Flutter SDK: 3.10.4

## Запуск
До запуска приложения рекомендуется выполнить обновление зависимостей:
```bash
flutter pub get
```

Генерация иконки (уже выполнено в проекте, но доступно при необходимости):
```bash
dart run flutter_launcher_icons
```

Запуск приложения:
```bash
flutter run
```
